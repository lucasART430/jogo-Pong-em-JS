# 🎮 Jogo Pong em JavaScript

Um jogo clássico de Pong desenvolvido em JavaScript puro utilizando HTML5 Canvas, criado como projeto acadêmico para a disciplina de Computação Gráfica.

🎯 **[Jogar Online](https://jogo-pong-em-js.vercel.app)**

## 📋 Sobre o Projeto

Este projeto é uma implementação do icônico jogo Pong, originalmente lançado pela Atari em 1972. O jogo foi desenvolvido utilizando tecnologias web modernas, sem dependências de bibliotecas ou frameworks externos.

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Finalidade |
|------------|-----------|
| HTML5 | Estrutura da página e elemento Canvas |
| CSS3 | Estilização e layout |
| JavaScript | Lógica do jogo e animações |
| HTML5 Canvas API | Renderização de objetos e animações |

## 🎯 Funcionalidades

- Jogabilidade clássica de Pong
- Controle por mouse ou teclado
- Sistema de colisão com física realista
- Pontuação em tempo real
- Animações suaves utilizando Canvas API
- Design responsivo

## 🚀 Como Executar

### Opção 1: Jogar Online
Acesse diretamente: [https://jogo-pong-em-js.vercel.app](https://jogo-pong-em-js.vercel.app)

### Opção 2: Executar Localmente

1. **Clone o repositório**
git clone https://github.com/LucasArtoni1983/jogo-Pong-em-JS.git
cd jogo-Pong-em-JS

2. **Abra o arquivo HTML**
- Localize o arquivo `index.html`
- Dê duplo clique ou abra em seu navegador preferido

3. **Comece a jogar!**
- Use o mouse para controlar a raquete
- Ou utilize as teclas direcionais do teclado

## 🎮 Como Jogar

- Movimente o mouse verticalmente dentro do canvas para controlar sua raquete
- Rebata a bola e não deixe passar pela sua raquete
- Cada ponto é marcado quando a bola passa pela raquete do adversário
- O objetivo é fazer o maior número de pontos possível
